# What in the Square

A personal-use matrix puzzle web game that removes physical setup while preserving the child's choices, experimentation, and problem-solving strategies.

## Product specification

- [PRD Draft v0.1](docs/PRD.md)
- [Original project PRD](https://chatgpt.com/space/page_a792609a9b7481918e26c19147e15b29)

## First playable version

- One validated puzzle family with visible row and column criteria.
- Click or tap a card, then a square to place it.
- Scattered-card and stack layouts, shuffle, and reversible moves.
- Deterministic placement validation and on-request visual hints.
- Basic parent settings and local pause/resume.

Later versions add graduated guidance, session summaries, and optional voice interaction.
